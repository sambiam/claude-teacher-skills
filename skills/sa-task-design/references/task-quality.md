# What a good task looks like — and what disqualifies one

The specification, written out so the skill applies it rather than guessing.
If your department's task criteria differ, edit this file — it is the one the
skill treats as binding.

## The two things a task can be

**A hook.** Comes *before* the knowledge. Creates the need for the idea — the
student feels the problem the mathematics solves. Must be short. If the class
spends the whole lesson getting to the basic idea, the hook has eaten the lesson
and the explicit teaching never happened.

**A deepening.** Comes *after* fluency. The class can already do the procedure;
the task makes them use it somewhere the method isn't signposted, or turns the
question around, or asks for the best answer rather than an answer.

Anything that is neither is decoration.

## Non-negotiable properties

**Low floor, no ceiling.** Every student can do *something* in the first two
minutes — draw it, try a number, do the easy case. The strongest student in the
room cannot finish it in ninety seconds and sit back.

**No signposted method.** If the task is sitting in the exercise on parallelograms
and the answer is "use the parallelogram formula", there is no thinking in it.
The work must be deciding what to do.

**Reachable with what they already have.** The difficulty lives in the *seeing*,
never in a technique the class has not met. A problem needing an unmet method is
not a challenge, it's a wall, and students correctly conclude they were set up
to fail.

**One real observation at the centre.** The best tasks turn on a single noticing.
That noticing is the consolidation discussion and it is what the student keeps.

**An answer, or a defensible best answer.** Open-ended is not the same as
answerless. "Explore rectangles" is not a task. "Area 40, what is the smallest
possible perimeter" is.

## The four disqualifiers

1. **High bar to entry.** Requires advanced mathematics to even start. Rejected.
2. **Inquiry used to build core knowledge.** Discovery learning of the basic
   procedure. Inquiry is for *deeper understanding after* the basics are secure —
   never as the delivery mechanism for the basics themselves.
3. **Low ceiling.** *"The area of a rectangle is 40 and one side is 8, find the
   other side."* A capable student is done in ten seconds and the rest of the
   room is still reading. Turn it round: *"The area of a rectangle is 40. What is
   the smallest perimeter it can have?"* — same content, no ceiling, and now
   there is something to argue about.
4. **A whole lesson to reach the basic idea.** Especially fatal for hooks.

## The low-ceiling repair moves

When a candidate task has a ceiling, these six moves usually fix it. Use them
when generating rather than reaching for bigger numbers.

| Move | Before | After |
|---|---|---|
| Reverse it | Find the area | The area is 36; what could the shape be? |
| Optimise it | Find the perimeter | Which of these has the *smallest* perimeter? |
| Constrain the digits | Solve 3x + 4 = 19 | Using digits 1–9 once each, fill □x + □ = □□ to make x as large as possible |
| Ask how many | Find a solution | How many solutions are there? How do you know you have them all? |
| Remove the goal | Find angle *x* | Here is the diagram. What can you work out? |
| Ask which and why | Calculate all four | Which one doesn't belong? Make a case for each |

## Placing a task in the lesson

| Slot | Length | Purpose | Good genres |
|---|---|---|---|
| Starter | 5–8 min | Curiosity, retrieval-with-thinking, argument | WODB, estimation, Same/Different, Venn, goal-free, number talk |
| Post-teaching check | 5–10 min | Apply the new thing where the method isn't named | Open Middle, minimal pairs with a twist, one SSDD |
| Mid-lesson deepening | 10–20 min | Use the fluency for something | SSDD set, Venn, non-routine problem, Open Middle |
| Whole-lesson task | 40–55 min | Modelling, investigation, argument | 3-act, Citizen Math, thinking-classroom task, statistical investigation |
| Plenary | 5–10 min | Reflect, generalise, expose a misconception | Which-is-wrong, "always/sometimes/never", write the question |

## Which disposition a genre actually develops

This is the SA-specific judgement and it should be made deliberately, not
retrofitted.

- **Resilient** — genres with a real stuck point that is survivable: Open Middle
  optimisation, non-routine problems, thinking-classroom tasks, 3-act.
- **Resourceful** — genres where several representations or strategies compete
  and the student chooses: SSDD, modelling tasks, goal-free, estimation with a
  strategy share, Venn diagrams.
- **Reflective** — genres with a built-in look-back: WODB (why is every answer
  defensible), Same/Different, slow-reveal graphs, error analysis, "which
  method was better and why".

A task usually serves one strongly and one weakly. Claim one, not three.
