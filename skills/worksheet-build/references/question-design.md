# Question design

questions come from.

## Variation theory

Fluency questions are deliberately sequenced, not ten unrelated questions of
roughly equal difficulty. Change one important mathematical feature at a time
so students can notice what changed, what stayed invariant, and whether the
previous rule still applies:

```
3x + 4x
3x + 4x + 2
3x + 4x − 2x
3x² + 4x² − 2x²
3x² + 4x − 2x²
```

Dimensions worth varying, one at a time: coefficient, sign, variable,
exponent, number of terms, order of terms, presence of constants, multiple
variables, brackets, multiplication, division, fractional coefficients,
fractional powers, unknown coefficients.

Don't increase every dimension of complexity at once. Moving from `3x = 12` to
`3x + 7 = 12` changes one thing; moving to `3(x + 7) = 12` changes two, and a
student who fails it can't tell you which one broke.

Don't mix prerequisite skills before students have practised them separately.
Within each difficulty band, use descriptive subheadings so the progression is
visible — for example, for algebraic simplification:

> Adding and subtracting — simplify fully
> Multiplying terms — simplify fully
> Mixed practice — simplify fully

## Mild

Tests the core skill directly. Open with questions structurally identical to
what the lesson modelled, keep irrelevant complexity out, expose the structure
clearly, and introduce one additional feature at a time.

Mild does not mean trivial, and it does not mean repetitive. Avoid:

```
2x + 3x,  4x + 5x,  6x + 7x,  8x + 9x
```

That is one question asked four times. Use structured variation instead.

## Medium

Requires secure application of the same mathematics. May introduce negative
coefficients, multiple variables, indices, more terms, reordered expressions,
multiple operations, less obvious like terms, and simple multi-step
simplification.

Difficulty should come from mathematical thinking rather than unnecessarily
large numbers. Keep using variation theory here — Medium is not a random pile
of harder questions.

Put the hardest Medium question at roughly the level of the lesson's final
worked example, not beyond it. Anything beyond belongs in Spicy.

## Spicy — the formats

Spicy questions are genuinely more interesting, not longer versions of Medium.
Use several different forms of thinking across the section, and give each
question one clear purpose.

**Missing information.** Find `p` and `q`:

```
px + 3y − 2x + qy = 5x − 4y
```

**Reverse problems.** Find the missing expression:

```
4x² × ☐ = 20x⁷
```

**Comparing expressions.** Which expression is greater — or under what
conditions is one greater than the other?

**Always, sometimes, never.** Is `x² + x² = x⁴` always, sometimes or never
true? Justify.

**Create an expression.** Give a target and constraints:

> Create an expression that simplifies to `7x³ − 2x + 4`.
> It must contain at least six terms, at least one multiplication, at least
> two `x³` terms, and a pair of terms that cancels completely.

**Error analysis.** Present a believable piece of student work and ask exactly
where the reasoning fails. Target the misconception this topic reliably
produces.

**Generalisation.** Ask what happens for arbitrary values, and to describe or
prove it.

**Structured algebraic expressions**, where the index knowledge is
appropriate:

```
3x × (2x + 5x) − 4x × 2x

2x^(1/3) × 3x^(2/3) × 4x^(4/3) + x^(7/3)

(6x⁴ + 4x⁴) / (10x²) × 2x³ + 9x⁹
```

Also useful across all bands, and easy to forget: vary the required response.
Mostly "solve" or "simplify", but include some "find the error", "explain
why", and "which of these is different" — these check understanding that
purely procedural questions can't.

Keep reading load low in Mild and Medium, and avoid contexts that need
cultural or general knowledge to parse. The question should test the
mathematics, not familiarity with the setting.

## Researching Spicy questions

When web access is available, look at high-quality enrichment sources rather
than inventing every extension question from scratch: NRICH, Don Steward /
Median, Underground Mathematics, Cambridge Mathematics, Desmos Classroom,
Amplify Classroom, Open Middle, Illustrative Mathematics, and Australian Maths
Trust-style problems.

Search for the mathematical idea, not the worksheet topic. Instead of
"simplifying algebra worksheet", try "equivalent expressions reasoning NRICH",
"algebra generalisation Don Steward", "combining like terms Open Middle",
"indices algebra extension problem", "polynomial reasoning task".

Adapt the structure into an original question. Don't reproduce substantial
copyrighted question sets. Where an excellent interactive task exists, a short
link or QR-ready URL beats forcing it onto paper.

## Extra Spicy: the advanced challenge

If a class has students significantly ahead, include an optional challenge
requiring genuinely higher-level mathematics — not just uglier arithmetic.

For a student working around Year 11 Mathematical Methods level: polynomial
equations, factor and remainder theorems, algebraic proof, functions and
transformations, fractional indices, logarithms, nonlinear simultaneous
equations, parameter problems, optimisation, graphical interpretation.

> **Extra Spicy Challenge**
> Find all real values of `x` satisfying `x³ − 4x² − x + 4 = 0`.

Connect it loosely to the worksheet's theme where possible, mark it clearly
optional, and separate it visually from the expected work so nobody reads it
as a measure of failure.

Answer-sheet working for a challenge shows the intended method:

```
x³ − 4x² − x + 4 = 0
x²(x − 4) − 1(x − 4) = 0
(x² − 1)(x − 4) = 0
(x − 1)(x + 1)(x − 4) = 0
x = −1, 1, 4
```

## Open-ended questions

Where several answers work, label the supplied one "One possible answer:" —
never imply an open construction has a unique solution. Then check the example
actually meets every condition listed in the question; this is where
create-an-expression tasks most often fall over.
